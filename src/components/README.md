# UI Components & Artwork

- `Nav.tsx` and `EventActions.tsx` provide navigation, registration, and Discord links.
- `Sponsors.tsx` renders confirmed partners and sponsors from [`../lib/sponsors.ts`](../lib/sponsors.ts).
- `Clock.tsx` shows the event countdown.
- `Experience.tsx` renders the experience tabs using `AsciiScenes.tsx` and `AsciiCanvas.tsx`.
- `Mountains.tsx` provides ridge data for the ASCII scene library.
