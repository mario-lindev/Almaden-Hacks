# Original ASCII horse

The ASCII character grid is sampled from an original silhouette created with the built-in image-generation tool on November 9, 2026. It is not a third-party sports logo. The raster source is retained locally at `output/horse/rearing-silhouette.png`; the website ships only the character grid.

Prompt: Create a single ORIGINAL rearing HORSE silhouette for conversion into ASCII art on a hackathon website. Side profile facing LEFT, standing upright on two strong hind legs, two forelegs lifted and bent in front of chest, proudly arched neck, clear long horse muzzle, pointed ears, flowing mane and tail. Elegant athletic equine anatomy, readable negative space between all four legs. Solid black silhouette with minimal white cutout detail for eye and mane, on pure white background. Entire animal visible with ample margins, centered portrait composition. No text, no border, no sports logos, no lion, no emblem. This will be sampled into a character grid, so keep the outline clean and leg shapes distinct.

The canvas animates chest sway, foreleg flex, and tail drift at 25fps. It pauses offscreen and in background tabs, and respects reduced motion.
