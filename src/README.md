# Application Source

- [app](app/README.md): Next.js routes, the root layout, metadata, and styles.
- [components](components/README.md): UI components and canvas artwork.
- [lib](lib/README.md): Shared content and typed sponsor data.
- wgsl-env.d.ts: TypeScript declarations for WGSL shader imports.
