# Public Assets

Files in this folder are served directly from the site root.

- [marks](marks/README.md): Sponsor logos and attribution.
- gallop-motion.webp: Horse animation atlas used by Horses.tsx.
- gallop.jpg: Source artwork for the animation generator.
- horses.jpg: Retained horse artwork.

Regenerate the motion atlas with ../scripts/build-horse-motion.py when its source changes.
